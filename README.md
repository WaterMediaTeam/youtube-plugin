# 🔌 PLATFORM EXTENSION
WATERMeDIA extension, uses YTDPL to add support to way more platforms that doesn't have
native (java) support on PlatformAPI

This was done as a separated mod due to the weight of some libraries, some projects
doesn't need this extension at all


# 📺 SUPPORTED PLATFORMS
|  Platform  | URL            | NOTES                     |
|:----------:|----------------|---------------------------|
|  YOUTUBE   | youtube.com    | Requires constant updates |
|  FACEBOOK  | facebook.com   |                           |
| INSTAGRAM  | instagram.com  | Requires session cookie   |
| NEWGROUNDS | newgrounds.com |                           |
NOTE: not all platforms are supported because some of them are planned to be added on core watermedia
